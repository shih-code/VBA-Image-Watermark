# 使用說明（Excel 驅動型圖片兩階段批次浮水印處理系統）

一個 Excel 小工具，可以幫你把一整批照片自動蓋上浮水印（例如檔名、日期、備註文字），不需要一張一張手動處理，也不用另外安裝任何軟體。

---

## 需要準備什麼

- Windows 電腦
- 有安裝 Microsoft Excel

---

## 第一次使用前的準備（只需要做一次）

這個工具是用一份一份程式碼檔案的形式提供的，你需要先建立一個空白的 Excel 檔案，把程式碼放進去，執行一次之後，操作介面才會自動生成。步驟不長，照著做就好。

### 1. 建立一個新的巨集啟用活頁簿

打開 Excel，建立一個新的空白活頁簿，另存新檔時，「存檔類型」選擇 **「Excel 啟用巨集的活頁簿 (*.xlsm)」**，取個檔名存起來（例如「批次浮水印工具.xlsm」）。

### 2. 開啟 VBA 編輯器

按鍵盤上的 `Alt` + `F11`，會跳出一個新視窗，這就是 VBA 編輯器。

### 3. 啟用一個必要的元件

在 VBA 編輯器上方選單點 `工具` → `設定引用項目`，在跳出的清單裡找到 **Microsoft Scripting Runtime**，把前面的方框打勾，按「確定」。

### 4. 把程式碼檔案匯入進來

1. 到你下載的這個專案裡，打開 `VBA 本體` 資料夾，裡面會看到 19 個檔案（副檔名是 `.bas` 或 `.cls`）。
2. 回到 VBA 編輯器，左側會有一個「專案總管」視窗，裡面看得到你剛剛存的活頁簿名稱。滑鼠對著它**點一下滑鼠右鍵** → 選 `匯入檔案`。
3. 在跳出的視窗裡，把 `VBA 本體` 資料夾裡的檔案**全部選起來**（可以先點第一個檔案，按住鍵盤 `Shift` 再點最後一個檔案，一次全選），按「開啟」。
   - 如果你的 Excel 版本這個視窗不能一次選多個檔案，就重複「右鍵 → 匯入檔案」這個動作 19 次，一次匯入一個檔案，效果一樣。
4. 匯入完成後，左側「專案總管」裡應該會出現一長串檔案名稱（例如 `Mod_WorkflowManager`、`cls_Settings` 等等），代表匯入成功。

### 5. 第一次執行，生成操作介面

1. 關掉 VBA 編輯器視窗，回到 Excel 畫面。
2. 按鍵盤上的 `Alt` + `F8`，會跳出一個巨集清單視窗。
3. 清單裡找到 **「重繪操作台」**，點選它，按「執行」。
4. 稍等一下，畫面上會自動出現操作介面（拖曳方塊、幾顆按鈕），這樣就完成了。

之後每次打開這個檔案，直接就能看到操作介面，不需要再重複以上步驟。如果操作介面不見或跑版了，隨時可以再執行一次「重繪操作台」把它恢復原狀，不會弄壞你已經匯入或處理過的照片資料。

## 開啟檔案時記得啟用巨集

之後每次打開這個檔案，Excel 上方可能會出現黃色警告列，寫著「已停用巨集」或「安全性警告」，記得點選**「啟用內容」**或**「啟用巨集」**，不啟用的話按鈕會沒有反應。

## 怎麼使用

打開檔案後，你會看到一個操作畫面，上面有一塊可以拖曳的方塊，還有幾顆按鈕。

### 步驟一：決定浮水印要蓋在照片的哪個位置

用滑鼠拖曳畫面上那個橘色的方塊，放到你想要蓋章的位置（例如照片右下角）。這個位置之後會套用到你匯入的**每一張**照片上，不用每張照片分別設定。

### 步驟二：匯入照片

點擊按鈕：

- **「匯入整個資料夾」**：選一個資料夾，裡面所有照片都會一次匯入。
- **「手選特定圖片」**：自己一張一張挑選要處理的照片。

匯入完成後，切換到下方的 `Staging_Images` 分頁，你會看到已經匯入的照片清單。如果想幫某張照片加上文字備註（例如日期、地點），可以直接在該列的備註欄位打字。

### 步驟三：開始蓋印章

回到操作畫面，點擊**「啟動批次浮水印導出」**按鈕。

系統會問你要處理多少張照片、浮水印會蓋在哪個位置，確認沒問題後，靜靜等它跑完就可以了。跑完後會告訴你完成了幾張。

### 步驟四：找到成果

完成的照片會自動存放在一個叫「成果」的資料夾裡，跟你原本的 Excel 檔案放在同一個位置底下。直接去那個資料夾找就能看到蓋好浮水印的照片。

## 資料夾說明：哪些可以刪、哪些絕對不能刪

執行過幾次之後，你的 Excel 檔案旁邊會出現一個「作業資料夾」，裡面有三個子資料夾。搞清楚它們各自的身分很重要，才不會不小心刪掉自己真正的照片。

| 資料夾 | 這是什麼 | 可以刪嗎 |
| --- | --- | --- |
| 你原本存放照片的地方（你自己選的那個資料夾） | 你的**正本照片**，工具只會「讀取並複製」，**絕對不會**修改、搬移或刪除這裡任何一張照片 | **不要刪。** 這是你唯一的正本，弄丟了就真的沒了，工具本身不會動它，但你自己也要保管好 |
| 作業資料夾 → **匯入圖片** | 工具自己複製出來、拿來加工用的**工作副本**，不是正本 | 可以刪。就算整個資料夾被你手滑刪掉，最多就是重新匯入一次，你的正本照片完全不受影響 |
| 作業資料夾 → **成果** | 蓋好浮水印的**最終成品**，這是你真正要的東西 | **不要刪**，除非你已經把裡面的照片複製到你要的地方保存好了 |
| 作業資料夾 → 備份 → **斷點備份_日期時間** | 案子**進行中**時的安全防護——你選「結束並重印」時，系統怕重印過程出意外，先把當下成果存一份 | 可以刪，這只是案子還在跑的時候多一層保險，不是最終定案的東西 |
| 作業資料夾 → 備份 → **成果備份_日期時間** | 你選「開新案」時系統自動留下的**上一個案子的最終成品**——代表那個案子已經完整結束了 | **不要刪。** 這是完成品，不是中途保險，刪了等於把做完的成果丟掉 |

**最重要的一句話**：這個工具從頭到尾都只會**複製**你的原始照片，不會用「搬移」或「刪除」的方式去動它。就算你把「作業資料夾」整個刪光光重來，你電腦裡真正的照片正本，一張都不會少。

## 常見狀況

**Q：我加了新照片，想再跑一次，會不會把之前處理過的也重印一次？**
不會。系統會自動記得哪些照片已經處理過，重跑的時候只會處理新加進來的照片。詳細情境見下方「什麼時候會用到斷點續跑」。

**Q：我想砍掉重練，從頭開始一個新的案子怎麼辦？**
匯入照片前，系統會問你要不要「開新案」。選「是（開新案）」，之前的成果會自動先備份好，再清空讓你重新開始，不會弄丟舊資料。

### 什麼時候會用到「斷點續跑」？

如果你的使用方式是：**照片不是一次匯入完，是分好幾次匯入、分好幾次蓋印章**，這個功能就是為你設計的。舉個實際的例子：

> 你今天匯入了 50 張照片，蓋好印章。過了兩天，你又拿到 30 張新照片，想加進同一批一起處理。這時候你會：
> 1. 執行「匯入整個資料夾」，把新的 30 張加進去
> 2. 執行「啟動批次浮水印導出」

因為「成果」資料夾裡已經有上次那 50 張蓋好印章的照片，系統會自動發現這件事，跳出視窗問你：

- **選「是」（跳過續跑）**：系統只會處理新加的那 30 張，已經蓋過章的 50 張不會重印，直接維持原樣。**這是最常用的選項**，適合你的情境——一邊陸續匯入新照片、一邊蓋印章，每次只處理新的部分。
- **選「否」（結束並重印）**：系統會把目前成果資料夾裡的 80 張全部先備份起來，然後**全部重新蓋一次印章**。適合的情境是：你改了印章的位置或文字範本，想讓所有照片（包含舊的）都套用新設定重印一次；或是你確定這批案子告一段落了，想要一個乾淨的結束點。

**簡單記法**：不確定的話，先選「是」——它比較保守，不會動到你已經做好的東西，最多就是漏做而已（漏做的話再跑一次就會補上）。「否」會動到既有成果（雖然會先備份，但仍然是全部重印一次），確定要這樣做再選。

如果你每次都是「一批照片、處理完就結束、下次是全新的案子」，那你大概率不太會遇到這個問題——它只有在「成果」資料夾裡還留著東西的時候才會跳出來問你。
